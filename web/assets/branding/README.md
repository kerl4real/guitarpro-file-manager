# Guitar Pro File Manager branding

Matching indigo guitar-pick, score-page, and music-note branding.

- `logo.png`: transparent horizontal logo for dark backgrounds.
- `app-icon.png`: transparent full-resolution icon.
- `app-icon-{32,64,128,256,512}.png`: app and web icon sizes.
- `app-icon.ico`: Windows icon containing 16, 24, 32, 48, 64, 128, and 256 pixel sizes.

Generated using the built-in image_gen tool. Existing application assets and configuration were not replaced.

## Prompts

Icon: A desktop application icon for Guitar Pro File Manager with an indigo guitar-pick silhouette, stacked score pages, and a musical note. Periwinkle and deep navy palette matching the existing UI. Centered, no text, transparent background, recognizable at small sizes.

Logo: Use the generated icon as a reference and preserve its design. Create a transparent horizontal lockup with the symbol at left, “Guitar Pro” on the first line and “FILE MANAGER” on the second. Modern sans-serif typography in periwinkle and cool light gray for the dark navy UI.
